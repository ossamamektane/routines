# Routines — Update 35

This build reduces the empty space below the task-actions sheet while retaining room for the home indicator. It also keeps Update 34’s slower bottom-sheet motion and keeps the sheet and dimming on the same timing curve, including the wake-up sheet and nested picker. The iOS status-area tint uses React Native's built-in animation driver with matching durations. Reduced Motion remains supported. The sheets themselves are still in the WebView: this is a closer approximation, **not an exact copy of Bills' native sheet**. The native safe-area change and actual motion must be tested on iPhone.

The Update 31 launch crash remains **undiagnosed**. Update 32 restored the earlier launch shell and removed the native Settings component; this build retains that recovery approach but changes the native status-area tint animation. No iOS build or device was available, so launch recovery is not verified.

Browser tests checked sheet/tint animation frames, wake-sheet exit, nested sheets, small screens, languages, themes, and Reduce Motion. Reminder planning and replacement were tested with a simulated OS, but actual notification delivery, permissions, sounds, and locked-phone behavior remain unverified. The earlier louder-sound request was never implemented: reminders already use the iOS default sound, so there is no louder sound change to undo. This update does not claim to fix the reported delivery failure. iOS pending-notification limits apply; the app plans roughly 50 hours ahead and may need to be opened again to refresh reminders. Hourly wake-dependent tasks require New Day.

**Do not uninstall the existing app:** iOS may delete locally stored tasks. Back up the repository and preserve secrets and signing settings. Extract this ZIP into the repository root including `.github/workflows/main.yml`, then use the existing build/submission workflow. Install the TestFlight build as an update to the same bundle ID, not a delete/reinstall. Back up your tasks from inside the app once it opens.

Test launch, saved tasks, sheet position and keyboard on iPhone before relying on the build. For reminders, enable Task reminders in the app and notifications in iPhone Settings, then schedule a task a few minutes ahead and test with the phone locked. If launch still crashes or reminders do not arrive, provide the crash report/build number and the time, task type, app state and notification settings. Browser and mocked-OS tests cannot prove iOS launch or delivery.
